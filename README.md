# Sistema de Venda de Ingressos 🎫

Projeto desenvolvido em C++ para gerenciamento de usuários, ingressos e ocorrências com reconhecimento facial.

## Funcionalidades
- Cadastro de usuários
- Venda de ingressos
- Reconhecimento facial (70 bytes)
- Registro de ocorrências
- Geração de arquivos

## Tecnologias
- C++
- STL (vector, list)
